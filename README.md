# Partum Design · Portafolio comercial

Herramienta de venta para mostrar trabajo de Partum Design: casos destacados (Haften y BIOS), 14 sitios web con vista previa en vivo, logotipos, papelería y redes sociales. Sitio estático (HTML/CSS/JS), pensado a 100vh como presentación.

- `index.html` – estructura de las secciones
- `data.js` – contenido (sitios, logotipos, papelería, redes). Aquí se agrega trabajo nuevo.
- `assets/work` – imágenes grandes (lightbox) · `assets/thumb` – miniaturas · `assets/web` – capturas de los sitios

Atajos: ↑/↓ o Espacio para cambiar de sección, F para modo presentación, ←/→ en el visor de imágenes.

Agregar una pieza: guarda la imagen como `.webp` en `assets/work/` y una copia de ~640px en `assets/thumb/` con el mismo nombre, y agrégala en `data.js`.
